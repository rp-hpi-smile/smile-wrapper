# SMILE Wrapper Application

## Smart Monitoring for Individualized Living and Engagement

### Republic Polytechnic, School of Sports & Health

---

## Overview

Four standalone browser-based screening tools (SMILE-FA, Speech Signal Lab, PLR Screener, Pronator Drift) are unified into a single Vue 3 wrapper with a guided-dashboard onboarding flow, shared participant intake, and a combined summary screen — while preserving each module's core analysis logic as isolated sub-modules with clear boundaries.

- **Deployment URL:** https://rp-hpi-smile.github.io/smile-wrapper/

## Recommended Browsers

- Chromium-based browsers (Chrome, Edge, Brave, etc.)
- Firefox

## Usage

1. Scan face to login:
  - Scan patient's face to get patient's data and instantiate a session ID.
  - Click login to access app once patient is authenticated.
